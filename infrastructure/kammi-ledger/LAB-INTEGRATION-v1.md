# Lab integration v1

Existing authorized work retains its original contracts. Do not migrate running experiments.
Future branches submit their scientific/engineering bytes, ownership, stage requirements,
evidence classes and policy declarations to Library Lab.

Register inputs; seal direct members plus parent roots; bind specs; obtain actor grants and
stage authorization; acquire a fenced resource; open evidence through the exposure gateway;
start an attempt; execute; register receipts/results; close the attempt; seal and verify lineage.

Labs own hypotheses, thresholds, data, results and interpretation. Shared implementations
do not constitute shared scientific evidence. Keep each lab's inputs/splits/seeds/results separate.
Use artifact IDs across hosts/worktrees. Never copy ancestor receipt fields into descendants.
Never infer no contact from absent assertions. Historical import confers no live authorization.
Request new custody terms centrally; contextual memory tags may evolve more freely.

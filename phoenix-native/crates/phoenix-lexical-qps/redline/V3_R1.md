# REDLINE V3-R1 literal reranking

Date: 2026-09-18. This is a diagnostic-only experiment. It does not publish
or activate a V3 model.

The literal QPS candidate generator, tokenization, posting impacts, coverage
floor, and evidence production were frozen. Train, development, and test
queries were separated by the dataset qrels. SciFact has no official dev
qrels, so its train qrels were deterministically split by query identity into
an 80/20 train/dev partition. FiQA used its official train/dev files. Test
qrels remained untouched.

BEIR qrels contain positive judgments only. The trained arms therefore used
unjudged candidate documents as weak negatives. This is suitable for a
diagnostic direction check and is explicitly non-promotable.

## Results

Metrics are on the untouched test qrels. The candidate pool is the frozen
literal evidence pool; the baseline reproduces the prior literal frontier.

| dataset / arm | nDCG@10 | Recall@100 | MRR | MAP |
|---|---:|---:|---:|---:|
| SciFact / Phoenix literal | 0.61045 | 0.86639 | 0.58523 | 0.57360 |
| SciFact / Phoenix BM25F feature | 0.67571 | 0.87456 | 0.64832 | 0.63786 |
| SciFact / weak-negative V3-R1-Lex | 0.62604 | 0.87456 | 0.59227 | 0.57953 |
| SciFact / weak-negative V3-R1-all | 0.60596 | 0.87122 | 0.57371 | 0.56500 |
| FiQA / Phoenix literal | 0.18283 | 0.41284 | 0.25223 | 0.14358 |
| FiQA / Phoenix BM25F feature | 0.23188 | 0.47022 | 0.30090 | 0.18267 |
| FiQA / weak-negative V3-R1-Lex | 0.09553 | 0.42397 | 0.12760 | 0.07386 |
| FiQA / weak-negative V3-R1-all | 0.07583 | 0.36774 | 0.10412 | 0.06072 |

The BM25F feature-only arm is the clear signal. It recovers 6 relevant
documents from below top-100 on SciFact and 104 on FiQA, with only 2 and 35
test relevant documents respectively moving from the old top-10 below rank
10. It raises FiQA nDCG by 26.8% relative to the literal baseline and Recall
@100 from 0.41284 to 0.47022.

The trained arms are not valid model qualifications. Their weak-negative
training causes pathological weight concentration on FiQA and substantial
top-10 loss. This is a training-contract failure, not evidence against the V3
feature schema.

## Interpretation

The one-feature result confirms that a mundane lexical calibration step can
buy a large part of the current gap without transport or positional evidence.
The next trainer should begin from this arm and add features under stronger
constraints:

1. preserve the BM25F lexical direction as an anchored baseline;
2. use query-grouped hard-negative sampling with explicit provenance;
3. normalize or bound feature contributions before fitting;
4. select on development nDCG and top-10 loss together;
5. keep positional features in a separate arm.

The current weak-negative model must not be promoted or used to reject the
deployable V3 architecture.

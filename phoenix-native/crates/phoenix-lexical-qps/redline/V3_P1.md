# V3-P1 Positional Residual Authority

Status: sealed pre-judgment packet protocol.

## Scope

This experiment tests whether a bounded positional residual earns authority above the frozen BM25F lexical anchor. Candidate generation, tokenization, corpus, query splits, and test isolation remain unchanged. Rarity, transport, and joint multi-feature learners are excluded.

## Positional family

The private packet-selection diagnostic combines only existing normalized positional primitives:

`0.35 complete_span_quality + 0.30 ordered_span_quality + 0.15 ordered_fraction + 0.15 exact_phrase + 0.05 exact_field`.

This score is used only to stratify blind packets. It is not a serving score and never enters a judgment packet.

The residual arms are predeclared as one-dimensional bounded additions over the frozen BM25F anchor: minimum complete span quality, minimum ordered span quality, ordered fraction, exact phrase, and exact field. The alpha grid is `[0, 0.025, 0.05, 0.10, 0.15, 0.20]`; residual magnitude is bounded to `0.20`. No rarity or transport feature is permitted.

## Packets and review

Train and dev queries only; test qrels are never opened during packet creation or human review. Each selected query contributes four blinded items: positional disagreement, high positional evidence, matched-rank ordinary positional control, and the first candidate below rank 100 when available. Packet text contains only query, title, body, opaque packet id, empty judgment, and empty note. Scores, ranks, document ids, qrels, and stratum metadata remain in the private ledger.

The reviewer assigns exactly one label: `2` clearly relevant, `1` partially or plausibly relevant, `0` clearly nonrelevant, or `?` cannot determine. Only within-query `2` versus `0` pairs acquire authority. A 10–15% opaque repeat subset is reviewed independently. Any `2 <-> 0` reversal invalidates that packet and removes all pairs involving it; the query-group sufficiency gate is rerun after filtering. Other label disagreements remain uncertainty observations.

A dataset is scientifically eligible only when at least eight independent query groups contain both an explicit `2` and an explicit `0` after reliability filtering. Pair counts do not substitute for query groups. Train and dev authority groups remain disjoint from one another during selection and evaluation.

## Evaluation

The anchor is the frozen BM25F feature with positional serving weights zero. Alpha is selected from authoritative train query groups only, with ties preferring the smallest absolute alpha and then the lowest alpha. Dev authority is a held-out diagnostic gate. A selected arm is evaluated once on the untouched BEIR test split. Test results are confirmatory only after the authority and reliability gates pass.

Required receipts include protocol, source and binary hashes, packet/ledger hashes, label census, query-group sufficiency, reliability, pair hash, authority hash, candidate-universe hash, per-query concordance, alpha dose response, nDCG@10, Recall@100, MRR, MAP, rank migrations, and top-10/top-100 regressions.

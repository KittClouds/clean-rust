# JEV Information Density v0.8I — Controlled Contrast Basis

## Purpose and boundary

The narrow hypothesis is that supervised examples containing an exact,
single-fact choice flip improve local choice discrimination relative to
matched sham siblings. This is not a general contrastive-learning comparison
and does not test a new curation policy.

This protocol has two gates:

1. **Phase A — construction and audit.** Generate exact fact-flip and sham
   pairs, hold out entire contrast families, construct matched 100k occurrence
   banks, and independently validate their semantics and lineage. No model is
   loaded or queried in Phase A.
2. **Phase B — paired frozen-head run.** Eligible only after Phase A passes.
   It uses the pinned LFM2.5-1.2B-Base representation and the already-frozen
   v0.8G compiler recipe. This document does not start Phase B or authorize
   changes to v0.8G/H results.

Phoenix remains out of scope. No backbone weights change. Existing banks,
contracts, and evaluation files remain read-only.

## Pair construction

Each anchor produces three exact-world episodes over the same latent sample,
prior profile, runtime schema, candidate order, and single choice query:

| Episode | Relevant observation | Independent marker | Exact choice result |
| --- | --- | --- | --- |
| Anchor | `+` | `+` | first local sibling |
| Fact flip | `-` | `+` | second local sibling |
| Sham | `+` | `-` | unchanged from anchor |

The focus sensor is conditionally informative about a four-valued latent
cause. Its likelihood tables are strictly positive, and `solve_exact` computes
every target distribution. The independent marker is generated by a separate
factor of the same finite world. The sham is accepted only when its complete
posterior distribution equals the anchor distribution within `1e-12`.

The visible edit is a one-character `+`/`-` replacement at one evidence span.
Treatment and sham edits have the same character edit distance, span count,
and value length. Candidate definitions, candidate order, query, context code,
and all other visible fields are invariant within each pair. The primary
training episode has one query, so its affected-query set is exactly
`q_choice`; the certified sham has no affected query for that target.

Candidate 0 and candidate 1 are explicit same-parent local competitors. The
generator asserts an exact posterior argmax flip between them; it does not
force the posterior to a one-hot target.

## Family split and capacity-derived dose

The first twelve ontology/world families are training-only and the final four
are held-out contrast-evaluation families. Each training family contributes
1,000 candidate anchors (12,000 available pairs); each held-out family
contributes 500 evaluation anchors (2,000 held-out pairs). Family, template,
schema, and candidate semantic IDs are disjoint across the split.

The sealed v0.8G random training bank contains 25,015 eligible closed-choice,
four-candidate rows. A pair occupies two bank occurrences (anchor plus one
sibling), so the old bank permits at most 12,507 pair slots. The generated
training universe is the tighter limit at 12,000 pairs. After this capacity
check, the Phase-A dose is frozen at **5,000 anchors**: 10,000 of 100,000
occurrences (10%) participate in explicit pair structures. This is a
construction dose, not a claim about an optimum.

`D_train` is calculated separately from the exact training-signature
multisets. Because the anchor is shared and only one sibling occurrence is
swapped per pair, the expected distance is near 0.05, not 0.10. Pair
participation and learner-visible displacement are distinct quantities and
both are reported. No minimum `D_train` threshold is invented here; the paired
intervention itself, exact targets, and equal bank structure are the treatment
definition.

## Matched banks

Use the immutable v0.8G `R100*` materialized training rows only as the common
skeleton source. Remove the same 10,000 deterministic hash-ranked rows from
both copies; all removed rows are closed four-candidate choice rows. Add the
same 5,000 anchors and 5,000 sham siblings to **S100**, and the same anchors
and 5,000 fact-flip siblings to **F100**. Each bank therefore has exactly
100,000 supervised occurrences, identical decision-view counts, candidate
cardinality counts, roots/exposure counts, family counts, and common
skeleton. The new sibling occupies a stable paired slot in both arms.

The exact learner-visible distance includes serialized state/query text,
ordered candidate surfaces/semantic IDs, exact gold distribution, decision
view, source/authority, open/closed status, and loss-relevant role fields. Row
IDs, anchor bookkeeping, and certificates are excluded. The existing L3
surface-invariance pair list is also audited; controlled fact-flip/sham pairs
are not mislabeled as invariance pairs.

## Held-out evaluation and interpretation

The contrast evaluation bank contains anchor, fact-flip, and sham episodes
from the four held-out families. It supports pair-response measures:

- probability movement toward the newly correct candidate;
- argmax flip success on fact-flip pairs;
- prediction stability on sham pairs;
- response magnitude against exact posterior movement;
- unaffected-query locality (the first experiment has one query, so the
  target-specific sham invariance is the locality control).

The NewTight and legacy evaluation bodies are not read to construct Phase-A
banks. At a future Phase B, NewTight choice/hard-sibling results remain the
generalization panel; controlled held-out pairs are the direct intervention
panel. No composite score is defined.

## Frozen Phase-B reference (not launched here)

If Phase A passes and a separate execution receipt is issued, Phase B uses the
v0.8G frozen recipe without search: LFM2.5-1.2B-Base at the pinned revision,
exact-length/single-row/no-padding final-layer `mean_full`, dynamic 128-wide
MLP compatibility head, source-typed L3 loss, AdamW `2e-3`, batch 256, exactly
three epochs, and paired seeds `20260927`, `20260928`, `20260929`. Only the head
is trainable. Arm identities, this recipe, and evaluation definitions cannot
be changed in response to results.

## Phase-A acceptance

Phase A passes only if all generated episodes validate under the frozen v0.1
exact-world validator; every treatment pair changes exactly one relevant
observation and flips the exact MAP choice; every sham changes exactly one
independent observation and preserves the full exact target; train/evaluation
families and IDs are disjoint; both derived banks contain 100,000 unique group
IDs; the two arms have identical common rows, slot IDs, query/view counts,
candidate-cardinality counts, root/family exposure counts, and
surface-invariance pair events; and a raw-record recomputation confirms the
training-signature distance and all source/output hashes.

Artifacts and generated corpora stay under
`D:\\codex-runs\\jev-information-density-v08i\\`; generated runs are not
committed to the repository.

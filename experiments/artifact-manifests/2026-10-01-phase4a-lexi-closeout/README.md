# Library closeout: Lepori Phase 4A and Lexi H2

This records Lepori's bidirectional Phase 4A lane and Lexi's H2 rebuild artifacts in Kammi Library CAS. Each imported file was streamed from its original root through the Library's hash-verifying local import route. The artifact_id equals SHA-256 of the original bytes; event_id is the Library registration receipt. Per-file source modification timestamps, relative paths, sizes, hashes, and registration events are retained.

The public Git commit contains only source, reports, and these inventories. Model weights, datasets, checkpoints, feature arrays, runtime files, predictions, and other run outputs are absent from GitHub; their bytes are in local Library CAS and their original paths are recorded in the indexes.

Lepori's Phase 4A disposition is state motion without useful computation; this is an archived result, not a promotion or causal-versus-encoder win. Lexi's source lock remains READY_FOR_FROZEN_HEAD_CONTROLS; this custody operation does not alter that scientific status.

Excluded from ingestion and Git staging: Python bytecode caches (__pycache__, .pyc, and .pyo); one lepori-causal-minicpm qualification file. The original files were left untouched.

# Phase6F — semantic observability and identifiability

No model, readout, adapter, or dataset training/mutation. Fixed inherited
conditional EXECUTE population:1333 TRAIN/333 DEV canonical roots, two renders,
all candidates. Protected EVAL unopened. Source pins and all public/data shard
hashes verified. Every public row must reproduce exactly from the renderer.

Three distinct evidence levels: (1) semantic-equivalence collisions after
removing wording/order; (2) exact permitted-interface collisions including full
text; (3) admissible hidden-fact counterfactuals with BYTE-IDENTICAL permitted
inputs and different legality. Semantic equivalence alone does not prove an
absolute Qwen ceiling: wording/order may carry information. No collision in a
finite unique-world sample does not establish identifiability.

Semantic transcript includes only values source-traced to actually emitted
records, source/confidence, visible validity annotations, gate rules, actor,
introduced bindings/aliases, public goal mentions/prose, costs, denied policy,
escalation rules, query questions and public request text, typed candidate menu.
Unknown bindings stay UNBOUND; no truth entity location repair. Hidden facts,
support labels, slot markers, selected IDs, distances and supervision excluded.
Render reconstruction can access canonical fields ONLY to certify this inverse;
the observable oracle never reads truth labels/hidden values as evidence.

Primitive canonical clauses are exactly Sim.Act.pre and .neg at tick0. No
implicit entity-existence or permission clause is invented. Gate STATE clauses
are included, since those rules are rendered. Permission is separate policy.

Strict three-valued oracle: active direct record true; visible conflicting
functional location/attribute false; otherwise unknown. Reported claims remain
claims, not certain truth merely because confidence is high. Scheduled inactive
records cannot exclude an unseen static record. Positive/negative polarity is
then applied; any false clause CERTAIN_ILLEGAL; all true CERTAIN_LEGAL; else
UNRESOLVED. Precision measured against independent simulator derivation.
Functional-slot inference is explicitly licensed by the pinned domain, not
learned from truth. A separate recipe-qualified oracle treats absent graph
predicates closed-world ONLY if the entire audited population has no hidden
slot markers/hidden graph facts; this additional assumption is not silent.

Candidate signatures include whole permitted semantic state plus candidate
coordinates, not just a local projection. Root signatures include ordered full
menu. Exact fingerprints retain raw text. Candidate scalar-score equivalence
does not automatically bound arbitrary root-level set predictors. Root exact-set
ceilings are empirical modal legal-vector mass per root-equivalence class.
Same-type ceilings explicitly condition on gold logged type (diagnostic side
information), not a type supplied to Qwen. Root counts use primary rendering;
both renders are independently retained and renderer leakage checked.

Counterfactuals replace ONE hidden, unreported, untimed AT/HOLDS/CONTAINS/STATE
fact with another same-domain value. Partitions/references are updated in a
private copy; observed facts/reports/menu/goals stay fixed. Algebra must still
derive EXECUTE, the pinned renderer/public channel must remain byte-identical,
and simulator legal sets must differ. Store every successful witness. These are
checked semantic worlds, NOT newly sealed corpus rows or claims a generator
seed emits them. Test both renderings before claiming robust paired ambiguity.
All within-schema replacements attempted in deterministic order until one
witness per root, with attempts/censoring disclosed. Failure to find a witness
does not certify a root. No hidden toggles silently added to corpus.

Original-bank empirical ceilings and augmented-counterfactual audit ceilings
are SEPARATE. No counterfactual frequency is advertised as the bank's Bayesian
performance ceiling. Root partition: verified ambiguous / oracle certified /
unresolved-not-certified. Witnessed roots can coexist with oracle errors;
any certainty contradicted by a witness is an instrument failure to debug.

Disposition: >=10% DEV roots directly witnessed ambiguous -> partial
nonidentifiability (or localized gap if >=80% share one primitive predicate).
>=90% strictly certified and oracle precision1 with no direct counterexample
-> OBSERVABILITY_SUFFICIENT on that certified scope. Otherwise explicit
OBSERVABILITY_INCONCLUSIVE_ON_UNCERTIFIED_ROOTS, never assume sufficiency.
No optional learned oracle required: explicit executable rule oracle and known
solvable controls already test machine usability; no model training is opened.

Fresh process reproduces every clause/signature/oracle/collision/witness and
all reports. Hash seal after replay, original artifact identities preserved.

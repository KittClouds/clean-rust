# Q10-RH1-Q1: Real-Learner Canonical Runtime Equivalence

Q1 verifies the canonical coordinate-to-prefix representation on actual
hash-bound PF5 endpoint states. A fixed 8-group engineering sample is used.

For each fixture, two different visitation orders construct the same canonical
coordinate-to-prefix mapping. The runner compares canonical identity, tie hash,
committed f32 weight bytes, learner-order sequential-f32 readout bits, and
geometry metrics.

Q1 is a qualification-only bridge from the synthetic RH1-Q0 fixture to the
real learner machinery. It does not run RH1-F1, consume scientific seeds, run
behavioral probes, or authorize DH08B.

# Q10-GC1-PAR8: Conservative Validated Global Coalition Assembly

PAR8 is a fresh engineering identity. PAR1 through PAR6 were interrupted
before receipt emission and are non-authoritative. PAR8 assembles the sealed
local palette library into endpoint-wide candidate states using exact
sequential-f32 replay.

The runner consumes the sealed group order and validates palette topology,
canonical coordinate-to-prefix choices, committed f32 bytes, baseline-relative
prefix legality, ZERO fills, and parent gates before assembly. It preserves the
incremental geometry calculation as a diagnostic, but every candidate is
validated with a full PF5 geometry recomputation. Final DA2 geometry gates are
hard, and each completed endpoint is independently reconstructed from its
canonical global mapping.

The receipt records nested RH1 runtime bindings, parent hashes, exact replay
counts, whole-endpoint scores, candidate mappings, geometry, and independent
audit results. The write root is this PAR8 directory. No parent artifact is
modified. No behavior is probed and no result is promoted to scientific
evidence.

## Frozen assembly contract

- Four workers, beam width 48: 32 exploit states and 16 exploration states.
- Groups use the sealed descending baseline physical-support ULP burden,
  mismatch count, ascending palette size, support degree, and group-id order.
- Every group has one ZERO candidate. Unvisited groups are completed with ZERO.
- A same-coordinate identical prefix is allowed; a differing prefix is a hard
  conflict. Group order never decides a conflict.
- Temporary nonmonotonic states are allowed under the sealed intermediate
  guardrails. Final validity is evaluated only after complete PF5 geometry
  recomputation.
- Exact sequential-f32 readout is authoritative for every score.
- Whole-endpoint mismatch count is the primary global search score in this
  first endpoint-wide constructor.

## Interpretation boundary

An exact global target is a construction result only. A partial result is
constructor evidence, not endpoint infeasibility. PAR8 does not open a
behavioral experiment, does not test adaptive geometry, and does not promote
the result to a scientific finding.

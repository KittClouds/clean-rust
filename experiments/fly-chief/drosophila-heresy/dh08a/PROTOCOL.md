# DH-08A: Event-Local Residual Endpoint Sensitivity

Status before measured execution: `FROZEN_UNOPENED`.

## Lineage and question

DH-07R found that the adaptive feasible-null policy suppressed old-map expression more strongly than the endogenous residual policy. Its primary true-minus-null estimate was +0.003990621, with both frozen 95% intervals wholly positive. In the parallel-on context, however, cumulative acquisition-axis position diverged before behavior, so the final policy contrast does not isolate an event-local endpoint effect.

DH-08A asks a narrower question:

> On states generated by the endogenous parallel-off trajectory, does replacing one endogenous residual endpoint with its Q07-matched feasible endpoint immediately change old-map expression?

This estimates an event-local effect conditional on states visited by the true policy. It does not decompose the cumulative DH-07R policy effect.

## Fixed design

- One synthetic specimen from the frozen lineage.
- Fresh computational seed bundles: 8000 through 8031, exactly 32, with no top-up.
- Sides R and L; eligibility taus 4 and 16.
- Acquisition/reversal task and parameters inherited unchanged: 512 total trials, 16 cues, 12 delay steps, eta 0.05, glutamate sign -1.
- Canonical trajectory: parallel off, endogenous true-perpendicular endpoint committed at every reversal event.
- Qualification seeds: 9100 through 9105 only. They are never inferential samples.

At each of the 256 reversal plasticity events, begin from one immutable pre-intervention state and construct:

- `W_B`: committed common/base endpoint with interval eligibility suppressed;
- `W_T`: ordinary committed endogenous true-perpendicular endpoint;
- `W_N`: Q07 feasible matched-null endpoint constructed from the same `W_B` and `W_T`.

Evaluate the deterministic old-map margin function directly on all three weight vectors:

`M_B = M(W_B)`, `M_T = M(W_T)`, and `M_N = M(W_N)`.

The evaluator may read only task patterns, weights, denominators, biases, and action signs. It must not call the stochastic sampler, mutate neural state, advance RNG, alter work counters, allocate in the hot loop, or write learner fields. Evaluation order must not matter.

Record:

`delta_t = M_T - M_N`.

Then discard the shadow endpoints and commit exactly `W_T`. The canonical run must be bit-identical to the ordinary DH-07R true-perpendicular trajectory with instrumentation disabled.

## Committed endpoint contract

Every null endpoint must satisfy the frozen Q07 realized-geometry gates after f32 commitment:

- axial error divided by true endpoint norm `<= 1e-7`;
- relative total-norm error `<= 1e-7`;
- relative residual-norm error `<= 1e-7`;
- absolute residual cosine with the endogenous residual `<= 1e-5`;
- exact boundary-membership equality;
- zero changed coordinates outside permitted support;
- relative realized nonzero-support count difference `<= 0.01`;
- zero bound violation;
- zero hot-loop allocations.

Every trajectory must provide exactly 256 ordered, passing event receipts. No event may be omitted. Failure of one event invalidates the run.

Q07 matches permitted support and constrains realized support size, but it does not force identical realized nonzero coordinates. The intervention is therefore named a **Q07-matched endpoint substitution**, not a mathematically pure rotation-only treatment.

## Primary outcome and inference

For seed bundle `s`, define:

`D_s = mean(delta_t over 2 sides x 2 taus x 256 events)`.

The 32 seed-bundle values are the only inferential units. Events, sides, and taus are repeated measurements.

The sole primary test is two-sided against zero. Report the mean, sample standard deviation, standard error, paired 95% t interval, and a deterministic 20,000-resample seed-level percentile bootstrap interval using seed 2026091608.

Interpretation is frozen:

- If both intervals are wholly positive, the Q07-matched null endpoint immediately suppresses old-map expression more strongly on true-path states, matching the DH-07R sign.
- If either interval includes zero or the intervals disagree, event-local endpoint sensitivity is unresolved; the DH-07R result remains compatible with path-mediated dynamics.
- If both intervals are wholly negative, the immediate endpoint effect opposes DH-07R, making subsequent adaptive dynamics necessary for the cumulative sign reversal.
- Any integrity or manipulation failure invalidates the scientific comparison.

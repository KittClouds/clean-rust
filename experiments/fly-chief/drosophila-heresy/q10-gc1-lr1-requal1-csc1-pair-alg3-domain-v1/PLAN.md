# Q10-PAIR-ALG3-DOM1: deterministic unscreened compatible triple domain

Build a fixed, outcome-blind sample of mutually compatible triples from the
complete UVD0 pair domain and fresh ALG1 singleton descriptors. No geometry,
readout, validity, or pair outcome is consulted. A triple has three distinct
action IDs and pairwise disjoint changed-coordinate support.

The domain contains the first 256 unique canonical triples per context under
the frozen UVD0 order, with the third action selected by a stable hash-ranked
compatible scan. This is a closure qualification sample, not a repair search
and not a claim about the complete order-3 domain.

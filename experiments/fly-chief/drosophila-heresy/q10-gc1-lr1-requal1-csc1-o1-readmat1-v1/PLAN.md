# Q10-O1-READMAT1

## Purpose

Materialize complete order-1 singleton readout vectors from the fresh
current-lineage singleton domain. This is a new replay/materialization
identity; the sealed singleton campaign remains untouched.

The source singleton receipts are independently checked for byte, score,
geometry, and gate parity after exact current-runtime replay.

## Scope

- All 3,696 fresh nonzero singleton identities.
- All 8 contexts.
- Full exact sequential-f32 readout vector for every record.
- No pair or higher-order replay.

## Promotion gates

1. Fresh singleton parent status is complete.
2. All eight source shards are hash-bound.
3. Current runtime and fresh closure load successfully.
4. Every source mapping reconstructs legally.
5. Replayed weight hash, readout hash, score, geometry, and final gate match
   the source singleton record.
6. Exactly 3,696 unique records are materialized.
7. No source files change during replay.
8. No unexpected output file is written.

This identity is engineering-only. It does not open RESID1, order 4, AG1,
GC2, behavior, or scientific promotion.

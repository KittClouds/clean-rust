# Q10-CSC1-UVD0: unscreened compatible pair census

Engineering-only domain construction from the fresh current-lineage singleton
materialization. This identity performs no pair geometry evaluation, no pair
readout replay, and reads no historical pair outcome.

For each of the eight current contexts, enumerate every ordered canonical pair
of nonzero singleton actions from different groups. Exclude only structural
invalidity: duplicate action identity, same-group pairing, overlapping changed
coordinates, malformed binding, or exact no-op. A pair is retained regardless
of predicted geometry, singleton geometry, readout score, or later usefulness.

The output is an ordered JSONL domain per context with compact action
identities. Singleton details are resolved from the sealed singleton shards.
The pair index is context-local and the domain hash covers the exact ordered
JSONL bytes. This domain is the sole parent for the prospective algebra and
unscreened replay identities.

No success density, validity label, residual, or pair score is used in domain
selection. The only output claim is structural eligibility and coverage.

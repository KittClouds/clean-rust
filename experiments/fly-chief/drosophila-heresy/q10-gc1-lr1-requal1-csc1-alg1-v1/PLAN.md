# Q10-CSC1-ALG1: prospective pair algebra

ALG1 consumes only the fresh current-lineage singleton materialization, the
sealed UVD0 census, and the sealed deterministic UPAIR1 replay sample. It
performs no pair replay. It materializes the singleton action states from the
fixed fresh S state, then seals two prospective compound predictions before
UPAIR1 can execute:

1. `structural_composition`: apply the two disjoint canonical action maps to
   the same S bytes, without running the pair readout;
2. `f32_additive_formula`: apply the explicitly frozen operation
   `f32(f32(A + B) - S)` componentwise to singleton state values and to
   singleton readout values.

The structural prediction is the committed-state composition implied by the
disjoint action maps. The additive prediction is a separate arithmetic
hypothesis and may disagree through floating-point rounding. Geometry is
evaluated against each predicted committed weight state; readout utility is
predicted from the additive readout formula. UPAIR1 is the first identity
allowed to execute the sampled pair readout and must compare both predictions
with the realized pair.

No pair outcome, pair validity, historical pair result, global assembly,
behavior, or scientific seed is consulted. ALG1 is a prospective engineering
artifact only.

# O3-MASKMAT1

Materialized 225429 exact order-3 semantic records for `R tau4 set3` using the qualified localized readout path. The frozen reference has 123 residual rows.

The artifact stores exact mismatch and changed-from-reference bitsets plus raw output bits for the 123 residual rows. Localized readout parity was checked for all 225429 records against the existing FRONT2 hashes and scores.

# ff-s15-ask-01 — the ASK rung: can a dedicated cheap observer beat the existing head at "should we ask?"

C1 gave the cheap tier no ASK capability and C2a showed that more surfaces of the same backbone do not help. This rung trains a dedicated `SHOULD_ASK` head (linear, then a tiny MLP under a preregistered rule)
on the four locked 230M surfaces and compares it, at matched operating points, with the existing Rung 0 decision head's `P(ASK)`.

- Plan and criteria: [PREREGISTRATION.md](PREREGISTRATION.md) (one addendum, recorded before calibration). Result: [RESULTS.md](RESULTS.md). Receipts: [results/](results/). Harvest draft: [HARVEST-ENTRY.md](HARVEST-ENTRY.md).
- **Verdict: NO GAIN OVER THE EXISTING HEAD, for both the linear head and the MLP.** The linear head is the existing head again; the MLP is modestly better (+13% AP) but misses the 1.25× bar.
  The existing head already asks at about 50% precision and 15–20% recall; adding the rule costs the acting tier nothing.
- Follow-up: the NLI-UNKNOWN oracle-headroom census (`../ff-s15-nli-census-01`) found the NLI route dead at its ceiling (a perfect NLI veto adds +6.7%, bar 25%).
- DEV only (TRAIN to fit, C1's CAL/HOLD to calibrate and score). No TEST row was read. HOLD has now served C1 and this rung, so it is not virgin; confirmation needs the fresh sealed split.

## Run it

```bash
python run_ask.py train     --head linear   # ~5 min: verify Rung 0 hashes, train on TRAIN, run on DEV features (needs a CUDA GPU for torch)
python run_ask.py calibrate --head linear   # CAL only: fit ASK thresholds, write policies, freeze
python run_ask.py score     --head linear   # HOLD through the C0 runtime, criteria A1-A3, verdict (once per head)
python run_ask.py train --head mlp          # only accepted if the preregistered condition holds (checks the linear report)
python tools/make_results.py                # RESULTS.md from results/ (guards fail if a prose claim stops matching)
python -m unittest                          # 10 tests on synthetic data
```

Depends on C0 and C1 (imported unchanged) and on C1's `evidence/` (verified against C1's tracked `results/freeze.json`) and the Rung 0 artifacts on `D:` (see C1's README).
`evidence/` is git-ignored and regenerated by the commands above.

# Mixed Corpus Bridge v0.1

This crate builds a small, validated research pilot from exact synthetic
episodes and source-shaped external fixtures. It emits only metadata reports
to `D:\codex-runs\jev-corpus-bridge-v01` and never downloads corpora into the
repository.

The source parsers are exposed under `adapters`; census, overlap, lineage, and
provisional split policies are implemented here. The pilot manifest is
descriptive, not a training mixture prescription.

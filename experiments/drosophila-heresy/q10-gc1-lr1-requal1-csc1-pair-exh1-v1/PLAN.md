# Q10-PAIR-EXH1: complete order-2 structural validity census

EXH1 consumes the complete 840,704-pair UVD0 census and performs no pair
readout. It constructs each compatible compound state from sparse singleton
weight deltas, evaluates the inherited geometry contract, and retains the
complete valid frontier for FRONT1.

The fast evaluator is not trusted by assumption. Before any full-domain
classification is promoted, it is reconciled against every 17,712 UPAIR1 pair
that has an exact AB replay. A validity disagreement blocks EXH1. Geometry
field differences are recorded; the validity gate is the promotion criterion
because that is the object used to enumerate the admissible frontier.

Output contains only valid-pair records and per-action valid-partner degree
maps. The UVD0 domain remains the authoritative complete structural domain;
absence from the valid frontier means invalid under the validated geometry
evaluator, not missing data.

This is engineering-only. No readout, global assembly, GC2, AG1, behavior, or
scientific seed is opened.

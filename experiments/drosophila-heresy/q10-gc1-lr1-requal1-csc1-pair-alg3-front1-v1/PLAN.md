# Q10-PAIR-ALG3-FRONT1: exact readout of the sampled valid triple frontier

FRONT1 consumes only the 20 triples marked structurally valid by the sealed
ALG3 geometry qualification. It executes exact sequential-f32 readout for
that frozen frontier and checks for a distinct exact target-readout endpoint.
This is an engineering sample result, not an exhaustive order-3 census and
not global feasibility.

# Q10-GC0-LR1-PAL2: Exact Augmented Candidate Palette Qualification

PAL2 is the corrected cancellation-augmented palette identity. It is a new
engineering qualification child of MAT1-R1 and the frozen LR1 runtime.

It materializes, with the exact LR1 oracle, one ZERO choice for every group
in all eight LR1 contexts and all 58 singleton receipts classified
`VALID_ADVANTAGE_PRESERVED`. It imports the 201 already materialized
successful pair motifs from MAT1-R1 without recomputation. No global beam,
global assembly, behavior, or scientific promotion is performed.

For each context the audit records exact committed bytes, readout bits/hash,
score, geometry, physical support, changed rows, fixed/damaged target rows,
and signed constraint-action vectors. It then audits support coverage and
group/coordinate compatibility conflicts separately by context.

The earlier PAL1 pair-only audit remains immutable as a diagnostic. PAL2 is
the first support audit whose library contains the planned ZERO, singleton,
and compound-pair entry classes.

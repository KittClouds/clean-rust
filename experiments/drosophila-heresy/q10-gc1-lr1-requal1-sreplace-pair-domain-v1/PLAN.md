# REQUAL1-SREPLACE-PAIR-DOMAIN: geometry-screened fresh pair opportunities

This engineering-only identity turns the complete fresh pair-eligible
singleton library into a deterministic compatible pair domain. It starts from
the same fresh invalid `S` state for both replacements, rejects overlapping
coordinate ownership, and screens the combined committed f32 state against
the hard final geometry gates before any sequential-f32 pair replay.

The screen uses only committed-byte geometry. Every retained opportunity is
then checked with the full PF5 geometry implementation before it is written to
the domain. No pair readout is evaluated here. Exact sequential-f32 pair
replay belongs to a later identity and is gated on this receipt.

The domain is a bounded engineering opportunity set, not a claim of global
pair infeasibility when an opportunity is screened out.

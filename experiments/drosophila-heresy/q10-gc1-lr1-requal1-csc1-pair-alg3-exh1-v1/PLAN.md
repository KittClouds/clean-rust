# Q10-ALG3-EXH1: complete order-3 structural validity census

This is an engineering-only exhaustive census of the frozen 125,506,560
canonical compatible order-3 action triples. It evaluates committed-state
composition and final geometry only. It performs no functional readout.

The structural domain is enumerated by three distinct action groups and one
of the eight frozen actions in each group. Pair validity is never used to
prune enumeration. It is consulted only after a triple is geometry-valid, to
label the number of valid order-2 subsets (`n2`). Singleton validity is also
retained as a descriptive `n1` label.

The fast geometry evaluator is qualified against the sealed 2,048-triple
ALG3 sample before the full census. Candidates within the frozen normalized
boundary guard of any hard gate use the authoritative full geometry path.
Fast and authoritative validity must agree on the qualification sample.

Invalid triples are represented by streaming counts, failure histograms, and
coverage hashes. Only valid triples receive compact frontier records. No full
weight state or readout is stored in this identity.

The result remains engineering-only. ALG3-FRONT2, GC2, AG1, behavior, and
scientific seed bundles remain closed until separately qualified.

# Q10-GC0-LR1-PAL1-R1: Augmented Cancellation Motif Palette Audit

This corrective child expands PAL1's compound-motif-only library with the
original valid singleton advantages and one ZERO choice for every group in
each LR1 context. The earlier PAL1 result remains immutable and is retained
as a pair-only support diagnostic.

This identity is derived and read-only. It performs no new candidate replay,
search, global assembly, behavior, or scientific promotion. The eight LR1
contexts remain separate.

The augmented entries are:

- ZERO for every available group;
- all singleton receipts classified `VALID_ADVANTAGE_PRESERVED` (58 total);
- all 201 materialized successful pair motifs.

For every entry the audit records canonical selection, committed mapping,
exact readout bits/hash, score, geometry, physical support, changed rows,
fixed/damaged target rows, and a signed constraint-action vector. It then
reports per-case readout and physical-support coverage, additive constraint
action rank, and group/coordinate conflict edges.

Support unions are capacity diagnostics only. They do not establish that the
entries can be jointly selected or that the global target is reachable.

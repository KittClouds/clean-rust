# Q10-GC1-RQ1: Bounded Counterfactual Replay Runtime Qualification

RQ1 creates a fresh bounded replay runtime for D1-R1 contextual removal and
CANCEL1 palette replacement. It does not run the removal/replacement
diagnostics, beam search, constructor, fresh-seed qualification, or behavior.
It patches no sealed PAR8/AUDIT1 artifact and reruns into no parent directory.

The runtime materializes complete group-to-candidate maps from baseline f32
bytes, baseline-relative legal prefixes, exact committed bytes, and exact
sequential-f32 replay with negative-zero initialization and bitwise parity.
Final validity uses full PF5 geometry recomputation and inherited DA2 gates.
No SIMD, reassociation, or FMA change to the oracle.

Classification has no unconditional fallback. Exact alternative requires zero
bitwise mismatch over every declared readout, W != T, W != B, and every final
validity gate. Valid advantage requires every final gate, W distinct from B/T,
and strict lexicographic baseline improvement. Target rediscovery, duplicate
choices, missing groups, illegal reserve, signed-zero differences,
no-improvement, and invalid-but-better fixtures receive correct non-success
status. Replacement is baseline-relative; a pair commits two distinct-group
replacements simultaneously from S. Same-group alternatives never combine.

Qualification uses fixed synthetic fixtures plus one previously exposed PAR8
case for bytewise oracle parity against the conservative PF5/GC0 path.
Throughput and peak memory are measured before workload caps are frozen.
Receipts use exclusive reservation, temp-file writing, atomic publication,
and terminal markers only after finalized hashes. Interrupted runs stay
explicitly incomplete.

Cost gates, pair budget, and shortlist rules for later stages are not sealed
here. RQ1 only qualifies the runtime and measurement method.

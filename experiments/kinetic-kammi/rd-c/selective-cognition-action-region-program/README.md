# Selective Cognition / Action Region Program

This is a downstream engineering and capability-characterization lineage under the System 1.5 Lab. It asks when a frozen observer can make a useful direct decision, what external signals identify such decisions, and how deterministic authority should defer everything outside that region.

The frozen specimen is:

```text
candidate producer
+ producer-order presentation contract
+ E009 v5 small and large observers
+ 850/150 action thresholds
+ deterministic authority and replay
```

E009–E011 remain historical evidence and unchanged. Their findings do not flow upstream into JEV, FAS, or other research claims. Lab Law supplies the broader System 1.5 and measurement-contract context; this README and dated experiment records hold current operating state.
